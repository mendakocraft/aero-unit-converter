# ✈️ AeroUnitConverter

**Aviation & Engineering Unit Converter / 航空・工学向け 単位換算ツール**

A lightweight, offline-ready web application designed for aviation mechanics, engineers, and technical professionals.

👉 **[Live Demo / アプリを開く](https://mendakocraft.github.io/aero-unit-converter/)**

## 🌟 Features (特徴)
- **8 Categories:** Length, Distance, Torque, Pressure, Volume, Weight, Speed, SI Prefix.
- **Fractional Inches (Dent & Scratch Limit):** Calculates the nearest 1/64 and 1/128 mixed fractions with mm/in difference for precision checks.
- **Bilingual Support (EN / JP):** One-tap toggle between English and Japanese.
- **Offline Ready:** Operates completely offline once loaded. Built with pure HTML/CSS/JS (No frameworks, No dependencies).
- **Responsive Design:** Optimized for both mobile devices and desktop screens.

## 🛠 Supported Units (対応単位)
* **Length:** in, mm, cm, ft, Fractional inches (1/64, 1/128 precision)
* **Distance:** NM, km, m, yd, ft
* **Torque:** in-lb, ft-lb, N・m, kgf・cm
* **Pressure:** PSI, bar, inHg, hPa / mbar
* **Volume:** Quart, Pint, US Gal, Liter, mL
* **Weight:** lbs, kg
* **Speed:** kt, m/s, km/h, mph
* **SI Prefix:** Giga, Mega, Kilo, Base, Centi, Milli, Micro, Nano
